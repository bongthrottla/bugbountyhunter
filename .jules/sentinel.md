## 2024-09-14 - Prevent Local Information Disclosure on Scan Results\n**Vulnerability:** The `outputs`, `scans`, `reports`, `wordlists`, and `configs` directories created by the application did not have strict permissions set, posing a risk of local information disclosure if other users had access to the system. Scan results can contain sensitive information.\n**Learning:** When generating files or directories that store sensitive operational data, it's essential to enforce strict file system permissions. Additionally, passing the mode to `os.makedirs` and explicitly calling `os.chmod` provides a defense-in-depth approach against TOCTOU vulnerabilities and system umask settings.\n**Prevention:** Use `os.makedirs(path, mode=0o700, exist_ok=True)` and follow up with `os.chmod(path, 0o700)` to guarantee secure directory creation.
